# FSDCSE21BACKEND

Assignments for the FSD backend labs. Each folder is its own small app.

| Folder | Run | What it does |
| --- | --- | --- |
| Assignments/Pages | `npm install` then `npm start` | Express reads HTML with fs. Home on `/`, about on `/about`. Port 3000. |
| Assignments/Portfolio | `npm install` then `npm start` | Personal portfolio. Port 3001. |
| Assignments/Product RestAPI | `npm install` then `npm start` | Product CRUD at `/products`. Port 3000. |
| Assignments/Product API | `npm install` then `npm start` | Same idea, plus a React page. Port 3002. |
| Assignments/Student Form | `node index.js` | Form that saves students into `students.json`. Port 3003. |
